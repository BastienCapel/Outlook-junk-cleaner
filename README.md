# Outlook-junk-cleaner

Workflow Mistral planifié qui nettoie le dossier Courrier indésirable Outlook :
chaque exécution déplace tous les messages du dossier `junkemail` vers `deleteditems`.

- Workflow : `outlook-junk-cleaner`
- Connecteur : `outlook` (résolu à l'exécution par la plateforme Mistral)
- Planification : toutes les heures via Mistral Studio.
